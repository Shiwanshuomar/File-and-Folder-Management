# Social Profile - File Management System

A small Express + EJS file manager. The project keeps text files in the local `files/` folder.

## Features
- Create text files
- Open/read file contents
- Edit file content and rename files
- Delete files with a confirmation prompt
- Search files by name
- Sort by name, recently modified, oldest modified, or largest first
- View file size and last-modified time
- Download a text file
- Basic filename validation and error handling

## Run locally
1. Install Node.js.
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` (or `npm start`).
5. Open `http://localhost:3000` in your browser.

Your existing sample files are in `files/`. The app creates this folder automatically if it does not exist.
